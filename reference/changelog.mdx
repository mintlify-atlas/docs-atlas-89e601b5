The changelog is the authoritative record of every release Flowy ships. Each entry documents what changed, what was added, and what was fixed — giving developers a clear picture of how the platform evolves over time. Because Flowy is currently in its pre-launch phase, the log is short; it will grow significantly beginning with the v1.0 public release in June 2026.

<Note>
  Flowy has not yet launched publicly as of this writing. The changelog will be updated with each release beginning June 2026. Entries below the upcoming v1.0.0 section reflect pre-launch milestones such as the documentation and landing page launches.
</Note>

## Upcoming: v1.0.0

<Info>
  **Expected: June 2026** — Initial public launch of the Flowy platform.

  This release includes:
  - **Public repository mind map generation** — paste any GitHub URL to generate an interactive mind map instantly
  - **Real-time Git Sync** — automatic map regeneration on every push via webhooks, with a sync-status indicator in the dashboard
  - **Interactive infinite canvas** — zoom, drag, Focus Mode, Layer Filters, and Node Search
  - **Management Module** — project dashboard with tags, folders, and Global Search across all saved maps
  - **GitHub OAuth** — secure private and enterprise repository access without leaving the browser
  - **Shareable map URLs** — public links that always reflect the latest synced state of the map

  See the full [Roadmap](/reference/roadmap) for everything planned at launch and beyond.
</Info>

## Pre-Launch

### 2025-07

**Landing page and waitlist launched.**
The Flowy landing page went live at [flowy-ebon.vercel.app](https://flowy-ebon.vercel.app), introducing the product to developers and opening the early-access waitlist. The page covers the core value proposition, all five product modules, key use cases, and the waitlist signup form. Initial feature design is complete across the Management Module, Pro Visualizer, Integrated AI, Pro Integrations, and Social Features.

---

### 2025-07 (II)

**Documentation site launched.**
The Flowy documentation site launched, covering all planned features, modules, and use cases in full detail. Documentation includes the [Introduction](/introduction), [Quickstart](/quickstart), module references for [Management](/modules/management), [AI](/modules/ai), [Integrations](/modules/integrations), and [Social](/modules/social), use-case guides for [Onboarding](/use-cases/onboarding), [Audit](/use-cases/audit), [Refactoring](/use-cases/refactoring), [Code Reviews](/use-cases/code-reviews), and [Living Docs](/use-cases/living-docs), and reference pages for [GitHub Integration](/reference/github-integration), [Webhooks](/reference/webhooks), [tsconfig Alias Support](/reference/tsconfig-alias-support), the [FAQ](/reference/faq), this Changelog, and the [Roadmap](/reference/roadmap).
