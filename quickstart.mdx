This guide walks you through everything from joining the waitlist to exploring your first interactive mind map. By the end you will have a live, navigable node graph of a real GitHub repository — and you will have connected Git Sync so the map updates automatically on every future commit.

<Tip>
  Start with a well-known public repository such as `https://github.com/vercel/next.js` or `https://github.com/facebook/react`. Public repos require no authentication, so you can experience the full mind map in seconds without any setup.
</Tip>

## Steps

<Steps>
  <Step title="Join the Waitlist">
    Flowy launches in June 2026. To secure your spot for early access:

    1. Open [flowy-ebon.vercel.app](https://flowy-ebon.vercel.app) in your browser.
    2. Scroll to the waitlist form at the bottom of the page.
    3. Enter your email address and click **Join now**.

    You will receive a confirmation once your early-access invitation is ready. Over 600 engineers have already joined — early invites are granted on a rolling basis as capacity opens.
  </Step>
  <Step title="Open Flowy">
    Once you receive your early-access invitation, follow the link in your email to open the Flowy web app. No installation is required — Flowy runs entirely in the browser. Sign in with the email address you used to join the waitlist.
  </Step>
  <Step title="Paste a GitHub Repository URL">
    On the Flowy home screen you will see a search bar with the prompt **"Paste a GitHub repository URL"**. Copy the full URL of any public GitHub repository — for example:

    ```
    https://github.com/vercel/next.js
    ```

    Paste it into the search bar and press **Enter** or click **Visualize**. Flowy immediately calls the GitHub API to fetch the repository's file tree and begins analysis.
  </Step>
  <Step title="Explore the Mind Map">
    Your interactive mind map loads within seconds. Here is what you will see on the infinite canvas:

    - **Root node** — the repository name sits at the center of the graph.
    - **Folder nodes** — each top-level directory branches outward as a named cluster, with nested sub-folders expanding as child nodes.
    - **File nodes** — individual files appear as leaf nodes, color-coded by type (TypeScript, CSS, JSON, and so on).
    - **Relationship edges** — import and dependency connections are drawn as lines between nodes, so you can trace exactly which modules depend on which.

    Use your mouse wheel or trackpad to zoom, click and drag the canvas to pan, and click any individual node to select it. Activate **Focus Mode** by clicking a node — the map immediately hides everything except that file's direct connections, letting you trace dependencies without distraction.
  </Step>
  <Step title="Enable Git Sync">
    To keep your map up to date automatically:

    1. Click the **Git Sync** button in the top-right toolbar.
    2. Flowy will prompt you to authorize the GitHub integration via OAuth if you have not done so already.
    3. Once connected, Flowy registers a webhook on the repository. From this point on, every push to the tracked branch triggers an automatic map refresh.

    The dashboard shows a traffic-light indicator for each of your saved maps — green means in sync with the latest commit, amber means a refresh is in progress, and red means the map is behind the branch.
  </Step>
</Steps>

<Note>
  Private repositories require GitHub OAuth authorization before Flowy can fetch the file tree. See [GitHub Integration](/reference/github-integration) for a full walkthrough of the OAuth flow, required permission scopes, and enterprise account support.
</Note>
