## What Flowy does

Navigating an unfamiliar or large codebase typically takes hours of scrolling, grepping, and guesswork. Flowy eliminates that friction by converting any GitHub repository into a visual hierarchy you can explore, filter, and share.

<CardGroup cols={3}>
  <Card title="Instant Mind Maps" icon="diagram-project">
    Paste a GitHub URL — get a complete visual hierarchy of the codebase in seconds.
  </Card>
  <Card title="Real-Time Git Sync" icon="arrows-rotate">
    Maps update automatically on every new commit pushed to the branch.
  </Card>
  <Card title="Focus Mode" icon="crosshairs">
    Click any node to isolate its direct dependencies and hide everything else.
  </Card>
  <Card title="AI Insights" icon="brain">
    Get AI-generated explanations, anomaly detection, and refactor suggestions per node.
  </Card>
  <Card title="Time Machine" icon="clock-rotate-left">
    Compare architecture across commits and PRs to track complexity over time.
